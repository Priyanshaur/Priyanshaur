## Projects

**[SafetyLens AR](https://github.com/Priyanshaur/AR_Mine_Workers_tutorial)** (Smart India Hackathon)
An offline AR safety-training app for mine workers, in English, Hindi and Santali. Completion certificates are HMAC-signed and can be verified by QR code.

**[FraudSight](https://github.com/Priyanshaur/fraudsight)**
Graph-based fraud detection with explainable alerts and a live red-team simulator. The README reports 98.8% accuracy on the usual test split and 72% on a harder out-of-window test, because the second number is the more honest one.

**[Pre-Delinquency Intervention Engine](https://github.com/Priyanshaur/TeamSolarians-Pre-Delinquency-Intervention-Engine)** (Barclays Hackathon)
Scores customers for financial stress before they miss a payment. Built on a synthetic portfolio of 5,000 customers with XGBoost, quantile regression and logistic regression: KS of 0.67 and 5.12x lift in the top decile. There's a Streamlit dashboard with SHAP explanations.

**[Krishi Mitra](https://github.com/Priyanshaur/Krishi-Mitra)**
The platform behind the IEEE paper: crop-disease detection from photos, a marketplace for farmers, IoT farm monitoring and multilingual support. React, Node, MySQL, Redis, FastAPI, PyTorch, Docker.

**[MotorSense](https://github.com/Priyanshaur/EDI_SEM_4)**
Vibration monitoring with an ESP32 and an accelerometer, streamed to a Flask app. Anomalies are caught with an Isolation Forest and One-Class SVM ensemble, tested on public bearing-fault data. Team project, [original repo here](https://github.com/PrathmeshVishwakarma/EDI_SEM_4).

**[Campus Nexus](https://github.com/Priyanshaur/Campus_Nexus)**
A distributed file-sync system with an anomaly-detection safety layer. Team project, [original repo here](https://github.com/PrathmeshVishwakarma/Campus_Nexus).
